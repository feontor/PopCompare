# PopCompare
Android quiz app that trains the sense of country population sizes.
Two choices, select the country with a larger population.
- Kotlin, XML layouts, Material 3
- MVVM with ViewModel, Room for persistence
- Min SDK 26, target SDK 36

## How to build and run
1. Clone the repository
2. Open it in Android Studio and let Gradle sync
3. Run on a device emulator (API 26+)

## How to test
Unit tests are in app/src/test. Run them directly from Android Studio or with `./gradlew test` in the terminal.
